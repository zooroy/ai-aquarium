# Spec Delta

## ADDED Requirements

### Requirement: 畫圖時暫停抓取
畫圖面板或「我的魚」清單開啟時，任何游標（手勢、滑鼠、觸控）SHALL 都不會抓起魚；如果開啟時已經有魚被抓住，那隻魚 SHALL 被放開並照常逃走。面板關閉後 SHALL 恢復抓取。

#### Scenario: 開啟面板時正抓著魚
- **WHEN** 使用者用手勢抓著一隻魚，同時用滑鼠按下「畫一隻魚」
- **THEN** 那隻魚被放開並逃走，面板開啟期間捏合也不會抓起魚

#### Scenario: 關閉面板後
- **WHEN** 使用者關閉畫圖面板後，在魚身上按下
- **THEN** 魚被抓起
