# Proposal

## Why

階段 ① 和 ② 完成後，魚缸會動，也能用手勢或滑鼠抓魚，但魚都是系統產生的。這次要做最初構想的最後一塊：讓使用者自己畫一隻魚放進魚缸。魚身就是畫布，用多色畫筆塗上花紋。畫好的魚會和其他魚一起群游，也可以被抓起來，重新整理頁面後仍然留在魚缸裡。

## What Changes

- **「畫一隻魚」入口**：
  - 畫面角落有一個小按鈕，按下後開啟畫圖面板。
  - 魚缸在面板後方照常動，但面板開啟時暫停抓魚。
- **畫圖面板**：
  - 畫布上顯示魚的側面輪廓（模板），只能在輪廓內上色。
  - 本次只提供 **1 種模板**，沿用現有的魚體型。
  - 工具：Cozy 色票（8～12 色）、三種筆刷大小、橡皮擦、復原、清除。
  - 用**滑鼠和觸控**畫圖，不支援手勢畫圖。
  - 按「放進魚缸」完成，或按「取消」關閉。
- **自訂魚進入魚缸**：
  - 把畫好的圖從側面平面投影貼到 Low Poly 魚身上，魚的兩側共用同一張圖，另一側左右相反。
  - 在 shader 裡做輕度色階化，讓手繪的顏色和 Cozy Low Poly 風格一致。
  - 新魚從畫面中央游出，再加入魚群，之後的群游、抓取、驚慌、逃走都和一般的魚相同。
- **保存與管理**：
  - 自訂魚存在瀏覽器的 IndexedDB，只在這台裝置上保存，重新整理後仍會出現。
  - 最多 **20 隻**自訂魚。達到上限時不能再新增，會提示先刪除。
  - 有一個縮圖清單，可以看到每隻自訂魚並刪除。
- **非本次範圍**：
  - 多種模板。
  - 重新編輯已經放進去的魚。
  - 手勢畫圖。
  - 跨裝置同步或分享。
  - 自訂魚的名字或其他屬性。

## Capabilities

### New Capabilities

- `fish-drawing`：畫圖面板，包括模板輪廓、畫筆工具、輪廓遮罩、復原與清除、開啟與關閉的流程。
- `custom-fish`：自訂魚的呈現（側面投影貼圖、色階化）、放入魚缸、上限與刪除，以及 IndexedDB 保存與載入。

### Modified Capabilities

- `fish-grab`：新增「畫圖時暫停抓取」需求，畫圖面板開啟時，任何游標都不會抓起魚，已經抓住的魚會被放開。

## Impact

- **新增程式**：
  - `src/ui/drawing-panel.ts`：畫圖面板的 DOM 介面。
  - `src/drawing/`：畫布、筆刷與復原的純邏輯，以及模板輪廓。
  - `src/storage/custom-fish-store.ts`：IndexedDB 存取。
  - `src/render/fish/custom-fish-renderer.ts`：貼圖與色階化 shader。
- **修改程式**：
  - `src/simulation/fish-state.ts`：魚的資料加上自訂魚的識別。
  - `src/simulation/grab.ts`：可以暫停抓取。
  - `src/app.ts`：整合入口按鈕、面板、自訂魚的生成與載入。
  - `src/config/params.ts`、`src/config/palette.ts`：新增參數與畫筆色票。
- **依賴**：不新增套件。IndexedDB 和 Canvas 2D 都是瀏覽器內建；node 測試用假的 storage 介面，不引入 fake-indexeddb，因為 Codex 的沙盒沒有網路。
- **效能**：
  - 每隻自訂魚需要自己的貼圖（例如 256×128），20 隻約 2.6 MB 的 GPU 記憶體。
  - 自訂魚用一個 InstancedMesh 加上 texture array，或每隻一個 mesh。20 個 draw call 也可以接受，方式在 design 決定。
